# AHAPOS 실물 검수 체크리스트 (90/91번 대상)

작성일: 2026-09-01(14번). 이 문서는 **후속 90/91번**에서 실물 AHAPOS 프린터가 준비된 뒤 채울 체크리스트다.
14번 작업에서는 실물 프린터를 확인하지 않았다 — 아래 항목은 전부 미체크 상태로 둔다. 가상 프리셋
(`virtual-80mm-8dpmm`, `virtual-58mm-8dpmm`)의 폭·DPI는 예시값이며 하드웨어 검증값이 아니다
(`docs/PRINTER_REFERENCE.md`, `hardwareVerified=false`).

체크는 **실제 종이 결과를 직접 본 사람만** 표시한다. 코드 리뷰·설계 문서·가상 출력 성공만으로 체크하지 않는다.
각 줄에 확인 날짜와 확인자를 채운다. 체크되지 않은 줄이 있어도 정상이며, 지우거나 done으로 덮지 않는다.

## 1. 준비물

- [ ] AHAPOS 프린터 본체 확보(브랜드만 확인됨, 정확한 모델명 미확인 — `docs/PRINTER_REFERENCE.md`)
- [ ] 프린터가 연결될 운영 PC(OS·브라우저 확정, 현재 설계 가정은 Windows 11 + Chrome/Edge)
- [ ] 실제 연결 포트 확인(USB/COM/LAN 중 무엇인지)
- [ ] 제조사 정품 드라이버/유틸리티 확보 경로 확인(시원아이티 자료실 `AHAPOSPrinterDriver.exe`는 다운로드/서명/안전성 미검증 상태 — 실행 전 재검토)
- [ ] 테스트용 영수증 용지(실제 폭 후보인 80mm/58mm 각각) 확보

## 2. 모델·사양 확인

- [ ] 본체 라벨 또는 드라이버에서 정확한 모델명 확인 (검색으로 나온 타 모델명을 대입하지 않는다)
- [ ] 프린터 큐 이름·드라이버명/버전 확인
- [ ] 감열 방식 여부 확인
- [ ] 실측 용지 폭(mm) 확인 — 설계 가정(80mm/58mm)과 실제가 같은지
- [ ] 실측 인쇄 가능 dot 폭 확인 — 현재 가상 프리셋(80mm: 640dot, 58mm: 464dot)과 대조
- [ ] 실측 DPI 확인 — 현재 가상 프리셋(8dpmm ≈ 203.2DPI)과 대조
- [ ] 이미지 명령 언어 확인(ESC/POS 여부 포함)
- [ ] GDI 비트맵 인쇄 및 사용자 지정 용지 길이 지원 여부 확인

## 3. 드라이버·연결 확인

- [ ] Windows에 드라이버 설치, 프린터 큐가 목록에 나타남 확인
- [ ] Windows 테스트 페이지 인쇄 성공
- [ ] 기존 인쇄 경로 확인(브라우저 직접 전송 / 로컬 서비스 / Windows 드라이버 등 중 실제 방식)

## 4. 작은 패턴 인쇄 검수

- [ ] 작은 흑백 비트맵 패턴 1장을 실제로 인쇄해 폭·방향(좌우 반전 여부)이 화면 미리보기와 일치하는지 확인
- [ ] 인쇄된 패턴의 실측 폭(mm)이 프로필의 `paperWidthDots`/DPI 계산값과 일치하는지 확인
- [ ] 한글 문구가 실제 종이에서 깨지지 않고 올바르게 나오는지 확인
- [ ] 이송(feed)·절취선 동작 확인(자동 커터 유무 포함)

## 5. 연속 인쇄 검수

- [ ] 네컷 샘플 여러 장을 연속으로 인쇄해 큐 처리·인쇄 간 대기·용지 밀림 여부 확인
- [ ] 연속 인쇄 중 실패(용지 부족/덮개 열림 등)가 실제로 발생했을 때 호스트가 정직하게 실패로 보고하는지 확인(가상 오류 주입이 아닌 **실물** 실패)
- [ ] 장시간(예: 수십 장) 인쇄 후 온도·인쇄 품질 저하 여부 관찰

## 6. 기록할 것 (실제 확인 후 이 문서에 추가)

1. 본체 모델명, 프린터 큐 이름, 드라이버명/버전, 포트 종류
2. 운영 PC의 OS와 브라우저, Windows 테스트 페이지 결과
3. 드라이버에서 읽은 DPI/인쇄 영역, 실제 작은 패턴의 폭과 방향
4. 긴 용지 설정, 한글과 사진 품질, 이송/절취, 연속 출력 결과
5. 기존 코드(`astraea` 저장소 등)에서 재사용한 파일·함수와 수정 이유

## 참고

- 브랜드와 큐 등록 정보만으로 검증 프로필을 활성화하지 않는다. 프로필 검증은 작은 패턴과 네컷 샘플의
  **실제 종이 결과**를 확인한 뒤에만 기록한다(`docs/PRINTER_REFERENCE.md`).
- 실물 검수 실패 후 다른 어댑터로 자동 전환하지 않는다(`AGENTS.md`).
- 이 체크리스트는 90(프린터 준비 후 조사)·91(실물 어댑터·검수) 작업의 입력이다. 현재 두 작업 모두 `deferred`
  상태다(`tasks/PROGRESS.md`).

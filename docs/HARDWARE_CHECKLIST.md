# AHAPOS 실물 검수 체크리스트 (90/91번 대상)

작성일: 2026-09-01(14번). 갱신: 2026-09-07(90번 — 장치 조사 결과 반영).

체크는 **실제 결과를 직접 확인한 근거가 있을 때만** 표시한다. 코드 리뷰·설계 문서·가상 출력 성공만으로
체크하지 않는다. 아래 `[x]` 항목의 근거는 전부 **사용자가 촬영한 본체 라벨/셀프테스트 출력물 사진**이거나
**인증된 저장소에서 직접 읽은 코드**이며, 각 줄에 근거를 적었다. 상세는 `docs/PRINTER_REFERENCE.md`.

**4·5절(실물 인쇄 검수)은 전부 미체크다.** 종이에 실제로 찍어 본 적이 없다.
`N/A` 표시는 이번 어댑터 결정(ESC/POS 직접 전송)에서 해당 항목이 경로상 필요 없어졌다는 뜻이며,
확인했다는 뜻이 아니다.

## 4. 작은 패턴 인쇄 검수

**전부 미체크. 여기가 91번의 핵심이며 최대 리스크는 첫 줄이다.**

- [ ] **래스터 이미지 명령이 실제로 동작하는지 확인** — 기존 코드는 텍스트·QR만 보냈고 이미지를 보낸 적이 없다. `GS v 0`을 보편 명령으로 가정하지 않는다(`PROJECT_RULES.md`)
- [ ] 작은 흑백 비트맵 패턴 1장을 실제로 인쇄해 폭·방향(좌우/상하 반전 여부)이 화면 미리보기와 일치하는지 확인
- [ ] 인쇄된 패턴의 실측 폭(mm)이 프로필의 `contentWidthDots 576` / 8dot/mm 계산값(72mm)과 일치하는지 확인
- [ ] 정사각 패턴으로 **세로 해상도(dotsPerMmY)** 확인
- [ ] 이미지 전송 분할 크기 확인 — 긴 네컷 스트립을 한 번에 보낼 수 있는지, 몇 줄씩 나눠야 하는지
- [ ] 한글 문구가 실제 종이에서 깨지지 않고 올바르게 나오는지 확인 (본 제품은 Canvas에서 글자를 이미지로 그리므로 프린터 내장 KSC5601에 의존하지 않는다 — 이미지 경로가 되면 자동 충족)
- [ ] 이송(feed) 실측 — 마지막 줄이 커터에 잘리지 않는 `trailingFeedDots` 결정
- [ ] 커팅 명령 종류 확인(부분/전체) 및 `cutStyle` 확정

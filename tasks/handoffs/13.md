## 바뀐 것
- `scripts/package-win.mjs` **신규** — `npm run package:win`: 웹 typecheck+build → `apps/print-host/wwwroot/`(재생성 폴더)로 복사 → `dotnet publish -r win-x64 --self-contained -o dist/win-x64`. AOT/ReadyToRun 미사용, 다른 폴더 미접촉.
- `package.json` — `package:win` 스크립트 추가.
- `.gitignore` — `apps/print-host/wwwroot/` 추가(재생성 산출물, `dist/`는 기존 규칙으로 이미 무시됨).
- `apps/print-host/Program.cs` — `!IsDevelopment()`에서만 `UseDefaultFiles()`+`UseStaticFiles()` 추가. 개발(Vite 5173)은 영향 없음. 이게 없으면 `wwwroot`에 웹을 넣어도 Windows 배포판이 화면을 서빙하지 못해 패키징 자체가 무의미해서 최소 범위로 추가함(WSL_DEVELOPMENT.md 6절 5항).
- `THIRD_PARTY_NOTICES.md`, `README.md` — 실제 publish로 확인한 Win32 Skia 네이티브·폰트 포함 사실과 `package:win` 사용법 추가.

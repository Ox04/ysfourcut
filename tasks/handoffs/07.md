## 독립 검수(Opus, 재디자인 금지)와 반영
- HIGH 3건: D1 촬영 넘침 / D2 배지 넘침 / D3 문서-실측 모순 → **전부 수정**. D3은 내 초기 자체 확인이 마지막 CSS 수정 뒤 좁은 화면을 재확인하지 않은 잘못이었다. 이후 검증을 눈이 아니라 **전 장면 수치 측정 스크립트**로 바꿨다.
- MEDIUM 6건 반영: 진행 표시(3/4) AX 노출, `--ink-faint` 정보성 텍스트 4곳 → `--ink-soft`(대비 3.6→6.3:1), busy 중 슬라이더/프레임 disabled(프리미티브에 disabled prop 추가), 재촬영 버튼 이름 `N컷 다시 찍기`, 카운트다운 라이브 영역 단일화(장식 aria-hidden, 낭독은 안내 문구 하나), 편집 넘침.
- LOW 반영: 포커스 링 잘림(버튼 12px 인셋), 슬라이더/문구 접근 이름에서 값 분리, 세션 날짜를 **prop**으로(UTC 하루 어긋남 해소, 고정은 10번), 촬영/편집/결과 sr-only h1, 프리뷰 라벨 role=group, `zoom` 미지원 엔진 `@supports` 폴백, 배출 효과 1회 재생(onAnimationEnd), `ResultView`에 rendered 전제조건 명시.
- 검수의 "잘한 점": fixture로 출력 성공 위조 경로 없음, 배율 정확, 터치 규칙 준수, reduced-motion 확실, 기존 게이트·장치 패널 회귀 없음.

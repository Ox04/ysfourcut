# 04 — 영수증 종이 외관 디자인

- 권장 모델: **Fable 5 / high**
- 입력: `04 진행해`
- 선행 작업: 03.
- 목표: .NET이 만든 PNG가 실제 감열 영수증처럼 보이도록 지면 외관 완성.

## 이번에 읽을 것

- 진행표, 03 handoff, 렌더링 인터페이스/프로필과 합성 코드.
- `VIRTUAL_PRINTER_DESIGN.md`의 4~6절과 12절 중 외관 조건.
- `SERVICE_DESIGN.md`의 5절 중 dot/mm 예시만.

## 할 일

1. 실제 생성된 content/paper PNG를 먼저 본다. 80mm/58mm와 짧고 긴 내용의 인공 샘플로 검수한다. 실제 인물 사진을 외부 서비스에 업로드하지 않는다.
2. 기존 Skia 엔진 위에 `ReceiptAppearanceRenderer`를 구현한다. 밝은 종이색, 아주 약한 섬유 질감, 종이 두께감과 자연스러운 바닥 그림자를 .NET에서 합성한다.
3. straight/tear/none 외형을 구분한다. 기본은 직선 절단이며 tear의 불규칙함은 선택 효과다. 사진을 절취선으로 자르지 않고 모든 흰 여백을 누렇게 덮어 내용 대비를 떨어뜨리지 않는다.
4. 최종 사진 픽셀과 paper 치수는 그대로 유지한다. 바깥 그림자는 물리 mm에서 제외하고 appearance에만 들어간다. 효과 seed/revision을 고정한다.
5. 기본 잉크 번짐/밴딩은 끈다. 실측하지 않은 AHAPOS의 농도·피드 오차와 100% 같다고 주장하지 않는다. 과도한 빈티지 오염이나 만화 같은 톱니를 기본으로 쓰지 않는다.
6. 실제 PNG를 열어 정확 보기와 외관 보기를 비교한다. 한 방향을 완성하고 불필요한 여러 스타일 후보를 계속 만들지 않는다. 웹 CSS 종이로 서버 결과를 대체하지 않는다.
7. `docs/RECEIPT_APPEARANCE.md`에 효과 파라미터, 색/그림자, 원점/배율, 검수 이미지 위치를 짧게 기록한다. 07/12가 이를 이어 쓴다.

## 완료 확인

- 세 가지 PNG가 실제 .NET에서 생성되고 content/paper 픽셀은 이전과 동일.
- 80/58mm, 최상단/최하단, 긴 스트립에서 내용 잘림 없이 자연스러운 외관.
- 동일 seed/revision의 결과 안정성, 메모리/출력 크기 한도 유지.
- 생성 코드를 작성한 것과 이미지를 실제로 눈으로 확인한 것을 구분해 보고.

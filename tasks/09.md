# 09 — 네컷 합성과 인쇄 비트맵

- 권장 모델: **Opus 5 / high**
- 입력: `09 진행해`
- OMC 입력: `/ys-task 09`
- 선행 작업: 02, 08.
- 목표: 한 가지 최종 1비트 데이터로 미리보기·다운로드·출력을 일치시킴.

## 이번에 읽을 것

- 진행표, 02/08 handoff, 촬영 원본 계약, 편집 UI 컴포넌트.
- `SERVICE_DESIGN.md`의 5절과 8절 중 bitmap 계약.
- `docs/PROJECT_RULES.md`의 촬영과 사진 처리 / 감열지용 이미지와 인쇄 절에서 이미지 항목만.

## 할 일

1. 원본 → 반전/크롭 → 목표 dot 크기 → 명암/그레이스케일 → 사진 디더링 → 흰 프레임/한글 → 최종 1비트 파이프라인을 구현한다.
2. 세로 1열 4컷, 사진 4:3, 기본 프레임 2개, 고정 촬영 날짜, 최대 24자 문구를 지원한다. 실제 프로필 폭을 입력으로 쓰고 80/58mm라는 이름만으로 dot를 추측하지 않는다.
3. Floyd–Steinberg를 기본으로 두고 ordered 비교 옵션을 제공한다. 사진은 목표 dot 크기에서 처리하며 한글은 로컬 폰트 로딩 완료 후 이미지에 선명하게 합성한다.
4. 순수 레이아웃/1비트 함수는 packages/imaging, 무거운 사진 처리는 Worker로 분리한다. 늦은 합성이 최신 설정을 덮지 않도록 revision을 검사한다.
5. 같은 최종 bitmap으로 웹 미리보기와 PNG 저장을 만들고 서버 입력 형식으로 pack한다. MSB-first, 1=검정, stride, 흰 padding, 상하 방향을 지킨다.
6. 프로필 변경 시 원본에서 다시 합성한다. 원본을 파괴적으로 보정하지 않고 최대 크기/문구/길이를 넘으면 설명 가능한 오류로 처리한다.
